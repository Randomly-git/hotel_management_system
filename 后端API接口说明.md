# 📝 后端 API 接口文档

**基础路径 (Base URL):** `[Your Server Address]:[Port]/api/v1`

**开发者:** 成员B (后端核心开发者)

## 模块一：口碑量化系统 (Feedback & Performance)

### 1. 客户反馈数据流入

| **方法** | **路径**    | **描述**                                                     |
| -------- | ----------- | ------------------------------------------------------------ |
| `POST`   | `/feedback` | **接收新的客户反馈。** 实时进行 NLP 情感分析和部门归因，并将结果写入 `customer_feedback` 表。 |

**请求 (Request Body):** `application/json`

| **字段**          | **类型** | **描述**           | **示例**                                 |
| ----------------- | -------- | ------------------ | ---------------------------------------- |
| `customerName`    | `string` | 客户昵称/ID        | `"张三先生"`                             |
| `feedbackContent` | `string` | 客户的原始反馈文本 | `"房间很棒，但前台服务员态度有些冷淡。"` |

**响应 (Response Body):** `HTTP 201 Created`

| **字段**               | **类型** | **描述**                       |
| ---------------------- | -------- | ------------------------------ |
| `feedbackId`           | `number` | 新创建的反馈记录 ID            |
| `sentimentScore`       | `number` | 实时情感分析得分 (-1.0 到 1.0) |
| `attributedDepartment` | `string` | 归因到的部门名称               |
| `message`              | `string` | 成功信息                       |

### 2. 部门绩效历史查询

| **方法** | **路径**               | **描述**                                                     |
| -------- | ---------------------- | ------------------------------------------------------------ |
| `GET`    | `/performance/history` | **查询指定日期范围内的部门绩效记录。** 供前端用于生成绩效趋势图表。 |

**请求 (Request Parameters):**

| **字段**    | **类型** | **描述**                         | **示例**     |
| ----------- | -------- | -------------------------------- | ------------ |
| `startDate` | `date`   | 查询的起始日期 (必填)            | `2024-10-01` |
| `endDate`   | `date`   | 查询的截止日期 (必填)            | `2024-10-31` |
| `deptId`    | `number` | 可选。部门ID，为空则查询所有部门 | `1`          |

**响应 (Response Body):** `HTTP 200 OK`

返回 `DepartmentPerformance` 实体列表，包含 `scoreIndex` (绩效指数)、`alertLevel` (预警等级) 等字段。

## 模块二：个性化服务系统 (Personalization & Task)

### 1. 任务生成 - AI 预测驱动

| **方法** | **路径**                   | **描述**                                                     |
| -------- | -------------------------- | ------------------------------------------------------------ |
| `POST`   | `/personalization/predict` | **模拟 AI 预测并自动生成任务单。** 供【入住系统】在客户Check-in时调用。 |

**请求 (Request Body):** `application/json`

| **字段**              | **类型** | **描述**               | **示例**         |
| --------------------- | -------- | ---------------------- | ---------------- |
| `memberId`            | `string` | 客户会员 ID            | `"VIP001"`       |
| `simulatedPrediction` | `string` | 模拟 AI 预测的客户需求 | `"需要额外枕头"` |
| `attributedDept`      | `string` | 模拟 AI 归因的部门     | `"房务部"`       |

**响应 (Response Body):** `HTTP 201 Created`

| **字段**     | **类型** | **描述**           |
| ------------ | -------- | ------------------ |
| `taskId`     | `number` | 生成的任务单 ID    |
| `assignedTo` | `string` | 任务分配的部门名称 |
| `message`    | `string` | 成功信息           |

### 2. 任务生成 - 客户主动请求

| **方法** | **路径**                   | **描述**                                                     |
| -------- | -------------------------- | ------------------------------------------------------------ |
| `POST`   | `/personalization/request` | **接收客户主动提交的请求并生成任务单。** 供【客户小程序/App】调用。 |

**请求 (Request Body):** `application/json` (复用 `FeedbackRequest` 结构)

| **字段**          | **类型** | **描述**         | **示例**                         |
| ----------------- | -------- | ---------------- | -------------------------------- |
| `customerName`    | `string` | 客户会员 ID/昵称 | `"VIP001"`                       |
| `feedbackContent` | `string` | 客户请求的内容   | `"请帮我把行李送到房间，谢谢。"` |

**响应 (Response Body):** `HTTP 201 Created`

| **字段**     | **类型** | **描述**           |
| ------------ | -------- | ------------------ |
| `taskId`     | `number` | 生成的任务单 ID    |
| `assignedTo` | `string` | 任务分配的部门名称 |

### 3. 任务查询与状态更新

| **方法** | **路径**                                                    | **描述**                                                     |
| -------- | ----------------------------------------------------------- | ------------------------------------------------------------ |
| `GET`    | `/personalization/tasks/pending`                            | **查询所有状态为 `PENDING` (待处理) 的任务单。** 供部门工作台展示。 |
| `PUT`    | `/personalization/tasks/{taskId}/status?status={newStatus}` | **更新任务单状态。** 供部门工作台操作任务完成或流转。        |

**PUT 请求参数 (Path & Query):**

| **字段** | **类型** | **描述**               | **示例**            |
| -------- | -------- | ---------------------- | ------------------- |
| `taskId` | `number` | 路径变量：任务单的 ID  | `/tasks/123/status` |
| `status` | `string` | 查询参数：新的任务状态 | `status=COMPLETED`  |

**可选状态值:** `PENDING`, `IN_PROGRESS`, `COMPLETED`, `CANCELED`

## 模块三：智能营收与动态定价系统 (Pricing)

### 1. 手动触发调价

| **方法** | **路径**          | **描述**                                                     |
| -------- | ----------------- | ------------------------------------------------------------ |
| `POST`   | `/pricing/adjust` | **手动触发动态定价模型，计算未来 7 天价格，并模拟同步全渠道。** |

**请求:** 无

**响应 (Response Body):** `HTTP 200 OK`

| **字段**  | **类型** | **描述** |
| --------- | -------- | -------- |
| `status`  | `string` | 结果状态 |
| `message` | `string` | 成功信息 |

### 2. 指定日期价格查询

| **方法** | **路径**           | **描述**                                                     |
| -------- | ------------------ | ------------------------------------------------------------ |
| `GET`    | `/pricing/current` | **查询指定生效日期的所有房型价格。** 供预订系统或前端展示使用。 |

**请求 (Request Parameters):**

| **字段** | **类型** | **描述**            | **示例**     |
| -------- | -------- | ------------------- | ------------ |
| `date`   | `date`   | 价格生效日期 (必填) | `2024-11-25` |

**响应 (Response Body):** `HTTP 200 OK`

返回 `PricingRecord` 实体列表，包含 `roomType`、`adjustedPrice`、`effectiveDate` 等字段。
