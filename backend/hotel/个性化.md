## 🌟 核心功能使用指南

### 功能一：API文档系统 (SpringDoc OpenAPI)

**用途**: 自动生成交互式API文档，支持在线测试

**使用方法**:
1. 启动应用后访问: http://localhost:8082/swagger-ui.html
2. 在页面中可以查看所有API接口
3. 点击任意API可以查看详细参数
4. 使用"Try it out"功能直接测试API

**优势**:
- 无需手动编写文档
- 实时同步代码更新
- 支持在线API测试

### 功能二：智谱AI自然语言处理

**用途**: 解析客户的自然语言请求，自动识别意图和分配部门

**API端点**: `POST /api/personalization/request`

**请求示例**:
```json
{
  "customerId": "VIP001",
  "requestContent": "房间太吵了，能不能换一个安静的房间",
  "roomNumber": "801"
}
```

**响应示例**:
```json
{
  "code": 201,
  "message": "客户请求已处理",
  "data": {
    "taskId": 1,
    "assignedTo": "房务部",
    "nlpAnalysis": {
      "intent": "ROOM_CHANGE",
      "description": "客户要求更换房间",
      "recommendedDepartment": "房务部"
    }
  },
  "timestamp": 1702678800000
}
```

**支持的请求类型**:
- 房间相关：空调、噪音、清洁、设施维修
- 服务相关：毛巾、饮用水、加床、送餐
- 前台相关：入住、退房、发票、问询

### 功能三：数据加密系统

**用途**: 保护客户敏感信息（身份证号、手机号）

**实现方式**:
- 使用AES-256算法加密存储
- 应用层透明加密/解密
- 数据库中存储加密数据

**使用示例**:
```java
// 创建客户画像时自动加密
GuestProfile profile = new GuestProfile();
profile.setIdCard("310101199001011234");  // 自动加密存储
profile.setPhone("13800138000");          // 自动加密存储

// 读取时自动解密
String idCard = profile.getIdCard();      // 返回明文
String phone = profile.getPhone();        // 返回明文
```

**数据库存储**:
- `id_card_encrypted`: 加密后的身份证号
- `phone_encrypted`: 加密后的手机号

### 功能四：租户隔离架构

**用途**: 支持多酒店数据隔离，实现SaaS架构

**实现方式**:
- 每个数据表添加 `hotel_id` 字段
- 所有查询自动过滤租户数据
- 完全隔离不同酒店的数据

**使用示例**:
```java
// 创建带租户隔离的任务
TaskOrder task = new TaskOrder();
task.setHotelId(1L);  // 设置酒店ID
task.setGuestMemberId("VIP001");

// 查询自动隔离
List<TaskOrder> tasks = taskOrderRepository.findByHotelId(1L);
// 只返回hotel_id=1的任务
```

### 功能五：AI预测任务生成

**用途**: 基于客户画像AI预测客户需求，提前准备服务

**API端点**: `POST /api/personalization/predict`

**请求示例**:
```json
{
  "memberId": "VIP001",
  "predictedNeed": "预测客户需要儿童座椅",
  "recommendedDepartment": "房务部"
}
```

**应用场景**:
- 根据历史入住记录预测需求
- 基于客户标签推荐个性化服务
- 提前准备常用物品

### 功能六：任务管理系统

**用途**: 完整的任务生命周期管理

**任务状态流转**:
```
PENDING → IN_PROGRESS → COMPLETED
    ↓           ↓
  CANCELED  ←  ──────
```

**主要功能**:
- 创建任务 (AI预测 + 客户请求)
- 更新任务状态
- 任务统计报表
- 批量操作支持

**API端点**:
- `GET /api/personalization/tasks/pending` - 查看待处理任务
- `GET /api/personalization/tasks/statistics` - 获取任务统计
- `PUT /api/personalization/tasks/{taskId}/status` - 更新任务状态

## 🔍 故障排除

### 常见问题及解决方案

1. **应用启动失败**
   - 检查Java版本是否为21+
   - 检查数据库连接配置
   - 查看启动日志中的错误信息

2. **智谱AI API调用失败**
   - 检查application-zhipu.yml中的API Key配置
   - 确认网络连接正常
   - 检查API Key是否有效且有余额

3. **数据加密/解密失败**
   - 检查AESUtil类的密钥配置
   - 确认加密算法版本兼容性

4. **数据库连接问题**
   - 检查云端数据库是否可访问
   - 确认数据库用户权限
   - 检查网络连接和防火墙设置

### 日志查看
```bash
# 查看应用日志
tail -f logs/hotel.log

# 查看特定模块日志
grep "ZhipuNlpService" logs/hotel.log
grep "AESUtil" logs/hotel.log
```
