# 个性化服务系统

## 🚀 快速启动

```bash
# 进入项目目录
cd backend/hotel

# 启动应用
./mvnw.cmd spring-boot:run

# 访问API文档
http://localhost:8082/swagger-ui.html
```

**环境要求**：Java 21+、MySQL 8.0+、智谱AI API Key（可选）

## 📡 完整API接口列表

### 1. 客户请求处理
**POST** `/api/v1/personalization/request`
```json
{
  "customerId": "1",
  "customerName": "张三",
  "content": "房间空调坏了，好热啊",
  "hotelId": 1,
  "roomNumber": "8801",
  "dueTime": "2025-01-18T18:00:00"
}
```

**功能**：智能解析客户请求，自动创建任务单并分发到相关部门

### 2. AI预测任务
**POST** `/api/v1/personalization/predict`
```json
{
  "memberId": "VIP001",
  "simulatedPrediction": "高楼层安静房间",
  "attributedDept": "房务部"
}
```

**功能**：基于客户画像预测需求，提前生成任务

### 3. 任务管理
| 方法 | 路径 | 功能 |
|------|------|------|
| GET | `/api/v1/personalization/tasks/pending` | 查看待处理任务 |
| GET | `/api/v1/personalization/tasks/statistics` | 任务统计 |
| GET | `/api/v1/personalization/tasks/{id}` | 查询任务详情 |

### 4. 部门任务管理
| 方法 | 路径 | 功能 |
|------|------|------|
| GET | `/api/v1/department-tasks/pending/{departmentName}` | 获取部门待处理任务 |
| GET | `/api/v1/department-tasks/new/{departmentName}/tasks` | 获取部门任务详情 |
| PUT | `/api/v1/department-tasks/{taskId}/accept` | 部门接受任务 |
| PUT | `/api/v1/department-tasks/{taskId}/complete` | 部门完成任务 |
| **PUT** | `/api/v1/department-tasks/manage/{taskId}/complete` | **管理端完成任务** |
| GET | `/api/v1/department-tasks/new/statistics` | 部门任务统计 |

### 5. 客户画像管理
| 方法 | 路径 | 功能 |
|------|------|------|
| POST | `/api/v1/personalization/profiles` | 创建客户画像 |
| GET | `/api/v1/personalization/profiles/{memberId}` | 获取客户画像 |
| PUT | `/api/v1/personalization/profiles/{memberId}` | 更新客户画像 |

### 6. **客户满意度评价** 🆕
| 方法 | 路径 | 功能 |
|------|------|------|
| POST | `/api/v1/department-feedback/submit` | **提交客户评价** |
| GET | `/api/v1/department-feedback/task/{taskOrderId}` | 查询任务评价 |
| GET | `/api/v1/department-feedback/customer/{customerId}/history` | 客户评价历史 |
| GET | `/api/v1/department-feedback/department/statistics` | 部门评价统计 |
| GET | `/api/v1/department-feedback/hotel/statistics` | 酒店整体统计 |
| GET | `/api/v1/department-feedback/task/{taskOrderId}/check-feedback-eligibility` | 检查是否可评价 |

## 🆕 新功能详细说明

### 管理端完成任务功能
**API**: `PUT /api/v1/department-tasks/manage/{taskId}/complete`
```json
{
  "departmentId": 1,
  "completionRemark": "空调维修完成，客户满意"
}
```
- 同时更新 `task_order` 状态为 `COMPLETED`
- 记录 `department_task` 实际完成时间
- 支持完成备注

### 客户满意度调查功能
**API**: `POST /api/v1/department-feedback/submit`
```json
{
  "taskOrderId": 1,
  "departmentTaskId": 1,
  "serviceRating": 5,
  "responseSpeedRating": 4,
  "serviceQualityRating": 5,
  "feedbackContent": "服务很好，工程师很专业",
  "feedbackTags": "专业,及时,满意",
  "isRecommended": true
}
```
- 多维度评分：服务、响应速度、服务质量
- 自动计算综合评分
- 支持文字评价和标签
- 推荐度调查

## 🔧 系统特性

### 🤖 智能解析
- **NLP引擎**：智谱AI GLM-4模型
- **意图识别**：房间服务、维修、餐饮、前厅等
- **部门分配**：自动推荐处理部门
- **降级处理**：AI不可用时分配给业务部

### 🔄 任务流转
```
客户请求 → AI解析 → 任务生成 → 部门分发 → 任务处理 → 完成确认 → 客户评价
```

### 🏢 多酒店支持
- 租户隔离：每个酒店独立数据
- 部门配置：支持自定义部门结构
- 权限控制：按酒店隔离访问权限

### 🔐 数据安全
- AES-256加密客户敏感信息
- 数据库字段级加密
- 应用层透明加解密

---

## 📊 数据库表结构

### 核心表
- **task_order**：客户任务单
- **department_task**：部门任务详情
- **guest_profile**：客户画像
- **sys_department**：部门信息
- **nlp_request_log**：AI解析日志
- **department_feedback**：**客户评价表** 🆕

### 部门配置
```sql
-- 已支持的部门
SELECT * FROM sys_department WHERE hotel_id = 1;
-- 工程部、服务部、餐饮部、安保部、业务部、前厅部、客房部、礼宾部等
```
